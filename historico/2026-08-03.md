## 📝 Decisões técnicas importantes

- **Bot do Telegram é uma rota do Next**, não um servidor separado. Menos coisa pra manter e pra pagar.
- **Railway só pro agendador**: worker pequeno que acorda de minuto em minuto e chama as rotas de cron da Vercel. Motivo: o cron da Vercel no plano Hobby só permite 2 disparos por dia, e os alertas de compromisso precisam de granularidade de minuto.
- **Regras da Apex no banco, versionadas por vigência** (`vigenteDe`). Regra nova = linha nova, nunca editar a antiga: contas já abertas continuam sob a regra em que nasceram. É o único modelo **sem** `userId` (regra da corretora é igual pra todo mundo).
- **Motor de cálculo é função pura.** Não toca no banco, não conhece nenhum valor da Apex — tudo chega por parâmetro.
- **Tudo em UTC no banco**, exibido em America/Sao_Paulo. O horário de verão americano muda a distância BR↔NY duas vezes por ano.
- **Transcrição de áudio via Groq Whisper**: a Claude API não processa áudio.
- **Repo git separado** pra esta pasta (mesma abordagem do Bot-trade-nt8), pra não misturar com o repo da home.

## ⚠️ Problemas encontrados e soluções

- **Problema:** `create-next-app` recusa pasta com letra maiúscula ("Socrates").
  **Solução:** criado em pasta temporária e movido pra cá.

- **Problema:** `EACCES` no cache global do npm (`~/.npm/_cacache`).
  **Solução:** `npm install --cache <pasta temporária>`.

- **Problema:** npm 11.18 bloqueia install scripts por padrão; Prisma e esbuild precisam deles.
  **Solução:** `npm install-scripts approve prisma @prisma/client @prisma/engines esbuild unrs-resolver`. Ficou gravado em `package.json#allowScripts`.

- **Problema:** Turbopack subia a raiz até a home (que tem um `package-lock.json` solto) e reclamava.
  **Solução:** `turbopack.root` fixado no `next.config.ts`.

- **Problema:** layout saiu meio quebrado — metade das classes do Tailwind não aparecia (`justify-between`, `size-11`, gradiente no texto).
  **Causa:** o Turbopack estava servindo CSS gerado de uma **versão antiga** do `page.tsx`.
  **Diagnóstico:** baixar o `.css` de `/_next/static/` e dar `grep` na classe que sumiu.
  **Solução:** matar o `next dev`, `rm -rf .next`, subir de novo.

- **Problema:** `capitalize` no CSS deixava a data como "Segunda-Feira, 03 De Agosto".
  **Solução:** `first-letter:uppercase`.

## 🤖 Proposta de comandos do bot (apresentada, aguardando "pode ir")

Princípio: **não decorar comando nenhum**. Fala normal e a IA descobre a intenção; comandos são só atalho.

| Comando | O que faz |
|---|---|
| `/start` | Amarra o Telegram à conta |
| `/hoje` | Tarefas + compromissos + status das contas |
| `/tarefas` | Lista com botões pra marcar feito |
| `/agenda` | Próximos compromissos |
| `/contas` | Painel: quantas liberadas, qual drawdown mais apertado |
| `/briefing` | Força o briefing fora das 09:00 |

Conversa livre (onde mora o valor):
- "marca pra eu ligar pro João amanhã às 15h" → agenda e confirma
- "fiz 180 dólares na 25k hoje" → lança o pregão, devolve saldo + dias qualificados + nova meta
- "iniciei uma conta 50k intraday hoje" → cadastra e calcula meta diária
- "terminei a academia" → marca a tarefa
- Áudio de qualquer uma dessas → transcreve e faz igual

Confirmações sempre com botão (✅ Confirmar / ✏️ Corrigir), pra não errar em silêncio.
